Why this exists

AI coding tools can run away with your quota.

Claude Code, Codex, Gemini CLI, and Cursor are powerful — but their plugin ecosystems can operate well beyond what you'd expect: scheduling autonomous sessions, granting themselves broad permissions, using the most expensive models without asking, and opening connections to endpoints you've never heard of.

By the time you notice, you're looking at a 39% quota remaining and a reset that's 18 minutes away.

🔓
Blanket permissions Bash(node .claude/*) lets any script in that directory run silently — no prompts
⏰
Scheduled workers Daemons that run audit and optimization jobs every few hours — burning quota on autopilot
💸
Model overrides Some plugins hardcode claude-opus-4-7 regardless of what model you selected
📡
Unknown outbound connections Background processes opening connections to IPs that aren't Anthropic's API
How it works

Simple by design.

No accounts, no relay servers, no subscriptions. One command gets you a live dashboard.

1

Install the agent

Run one command. It downloads a 15 KB Node.js agent to ~/.agentscope/, starts it in the background, and registers it with launchd (macOS) or systemd (Linux) so it restarts on login.

2

Agent reads your environment

Every 5 seconds the agent reads session files for Claude, Codex, and Gemini; scans settings from all detected tools; checks running processes; and monitors network connections — only when your browser is open, so it's zero-overhead otherwise.

3

Browser connects directly

The Monitor page opens a Server-Sent Events stream to localhost:4242. Data flows from your machine straight to your browser tab. Nothing passes through any server.

What it monitors

Every AI coding tool on your machine.

Six panels, one view. Refreshed in real time every 5 seconds.

📊

Session tracking

Hourly session counts across Claude Code, Codex, and Gemini with a 24-hour timeline. Spot the exact moment a daemon woke up and started burning quota.

🔑

Permission audit

Every allow/deny rule in Claude settings, Codex config, and Cursor rules — rated by risk. Blanket wildcards, full-auto modes, and model overrides flagged immediately.

🌐

Network connections

All outbound connections from AI agent processes. Anthropic, OpenAI, Google, and GitHub endpoints are whitelisted — anything else is flagged for your review.

⚙️

Process monitor

Live list of processes from all detected AI tools — PID, CPU, memory, and a risk label. Daemons, hook scripts, and unknown workers are flagged separately.

🚨

Automatic alerts

Critical and high-risk findings bubble to the top of the dashboard without you having to dig. Session surges trigger alerts too.

🔄

Update notifications

The agent checks for new versions and surfaces a one-line update command in the browser — no need to remember to update manually.

Privacy

Your data goes nowhere.

This site is a static file. There is no server, no database, no accounts. The agent runs on your machine and talks only to your browser.

The only outbound call the agent makes is a version check — fetching a small JSON file to see if there's an update. No conversation content or personal data is ever involved.

✓ Agent binds to 127.0.0.1 only — not reachable from other machines on your network
✓ Session content is never read — only file size and timestamp for session counting
✓ No tracking, no cookies, no analytics — the hosted site doesn't even know you visited
✓ MIT licensed — read every line at github.com/eternalsayed/ai-monitor
