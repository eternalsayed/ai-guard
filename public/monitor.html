Install the agent

One command installs a tiny local daemon that monitors Claude Code, Codex, Gemini CLI, and more — streaming data directly to this page.

Run in your terminal

1Downloads a single Node.js file (~15 KB) to ~/.agentscope/agent.js
2Starts it as a background process on port 4242 (127.0.0.1 only — not internet-accessible)
3Registers with launchd (macOS) or systemd (Linux) so it restarts on login
📁 ~15 KB on disk · 🧠 35–50 MB RAM · ⚡ <0.1% CPU when idle · 🔒 127.0.0.1:4242 only · 📡 1 outbound req/hr (version check)
▶ What exactly does this script do?
Reads (metadata only): session file sizes & timestamps from ~/.claude/, ~/.gemini/, ~/.codex/ — never conversation content
Reads: permission settings from .claude/settings.json, .codex/config.json, and .cursor/settings.json in your projects
Runs: ps aux to list AI agent processes, and lsof -i to list their network connections
Never reads: conversation content, API keys, tokens, or any .env files
Never sends: any data externally — one outbound call is a version check to /version.json
Uninstall: kill $(cat ~/.agentscope/agent.pid) && rm -rf ~/.agentscope
